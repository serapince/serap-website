# Serap's personal website

A single-page static site (plain HTML, CSS and JavaScript, no build step).

- `index.html`: the whole site. Content lives in the `PLACES`, `PROJECTS` and `POSTS` arrays near the top of the main script.
- Hosted with GitHub Pages from the `main` branch root.
- A `CNAME` file with the custom domain is added once the domain is known.
